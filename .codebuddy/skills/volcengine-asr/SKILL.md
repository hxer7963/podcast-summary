# volcengine-asr

火山引擎大模型 ASR 转录阶段。把**音频公网 URL** 转成纯文本 `transcript.md`。

## 与 podcast-transcribe 的区别

| 维度 | podcast-transcribe (vibevoice-asr) | volcengine-asr (本 skill) |
|---|---|---|
| 输入 | 本地音频文件 (`*.m4a` / `*.mp3`) | 音频公网 URL |
| 需要 GPU | 是 (`--dp 4` 占满 4 卡) | 否 |
| speaker 标签 | 有 (`[Speaker 1]`) | 无 (纯文本) |
| 需要 transcript-fix | 是 | 否 (可直接进 summary) |
| 需要先下载音频 | 是 | 否 (传 URL 给火山云) |
| 鉴权 | 无 (本地模型) | `VOLC_ASR_API_KEY` 环境变量 |

## 前置：开通火山云 ASR

完整开通步骤见 `docs/volcengine-asr-setup.md`。简述：

1. 在火山引擎控制台购买 Agent Plan 套餐
2. 在豆包语音 → 系统管理 → 开通管理 → 服务管理 → 大模型 里开通"录音文件识别 2.0"
3. 在豆包语音 → 语音识别 → 【右上角】API 调用 里设置 API key
4. `export VOLC_ASR_API_KEY="<your-key>"`

## 输入 → 输出

- **输入**：`--audio-url <url>`（或从 `--episode-dir/README.md` 的 `> Audio URL:` 行自动解析）
- **输出**：`<episode_dir>/transcript.md`（纯文本，无 speaker 标签）
- **stdout 约定**：成功打印 `TRANSCRIPT=<path>`

## 调用方式

### 方式 1: 直接传 audio URL

```bash
export VOLC_ASR_API_KEY="<your-key>"
python3 scripts/volc_asr.py \
  --audio-url https://example.com/episode.mp3 \
  --episode-dir "audios/xiaoyuzhou/硅谷101/E230-xxx"
```

### 方式 2: 从 README 自动解析 URL

如果 `podcast-fetch` 已在 `README.md` 中写入了 `> Audio URL: <url>` 行（小宇宙 / RSS 源已支持），则可省略 `--audio-url`：

```bash
export VOLC_ASR_API_KEY="<your-key>"
python3 scripts/volc_asr.py --episode-dir "audios/xiaoyuzhou/硅谷101/E230-xxx"
```

### 自定义轮询

```bash
python3 scripts/volc_asr.py \
  --audio-url <url> --episode-dir <dir> \
  --poll-interval 15 --max-wait 3600
```

## 环境变量

| 变量 | 必需 | 说明 |
|---|---|---|
| `VOLC_ASR_API_KEY` | 是 | 火山引擎大模型 ASR API Key |

## 关键约束

1. **audio URL 必须公网可访问**：火山云服务器会去拉这个 URL，本地路径 / 内网 URL 不行

2. **不需要本地音频文件**：这是本 skill 与 `podcast-transcribe` 的核心区别 — 直接把原始 URL 传给火山云，跳过音频下载

3. **输出无 speaker 标签**：`enable_speaker_info=False`（与 yt-dlp 字幕一致，`podcast-summary` 不依赖 speaker 标签）

4. **不需要 transcript-fix**：火山大模型 ASR 的英文专名 / 技术术语识别较好，可直接进 `podcast-summary`

5. **幂等**：如果 `transcript.md` 已存在且 ≥100 字节，跳过不重复转录

6. **轮询超时**：默认 30min，超长音频（>2h）建议用 `--max-wait 3600`

## transcript.md 格式

```markdown
# Transcription
> Audio URL: https://...
> ASR: volcengine bigmodel (request_id=xxx)
> Generated by volcengine-asr

纯文本转录内容...
```

## 在 pipeline 中的位置

当 `VOLC_ASR_API_KEY` 环境变量存在时，pipeline 可走火山云路径：

```
URL ──▶ podcast-fetch (下载音频, README 含 audio_url)
   ──▶ volcengine-asr (传 audio_url 给火山云)
   ──▶ podcast-summary (直接进 summary, 跳过 transcript-fix)
```

对比标准链路（vibevoice-asr）：

```
URL ──▶ podcast-fetch (下载音频) ──▶ podcast-transcribe (GPU) ──▶ podcast-transcript-fix ──▶ podcast-summary ──▶ ...
```

## 故障排查

| 现象 | 可能原因 | 处理 |
|---|---|---|
| `VOLC_ASR_API_KEY is not set` | 环境变量未配置 | `export VOLC_ASR_API_KEY=...`（见 `docs/volcengine-asr-setup.md`） |
| `submit failed: code=...` | API key 无效 / 配额耗尽 | 检查火山引擎控制台 |
| `polling timed out` | 音频过长或服务排队 | `--max-wait 3600` 重试 |
| `audio is silent` | 音频损坏或全静音 | 检查 audio_url 是否有效 |
| `no --audio-url given` | README 里没有 `> Audio URL:` 行 | 手动传 `--audio-url` 或检查 fetch 是否写了该行 |
